# Sortowanie uczniów
## Opis programu
 
Program służy do wczytywania danych uczniów z pliku tekstowego, zapisania ich w tablicy obiektów klasy Person, posortowania według nazwiska rosnąco oraz zapisania posortowanych danych do pliku wynikowego.
 
Program obsługuje maksymalnie 30 uczniów.
 
## Klasa Person
 
Dane jednego ucznia są przechowywane w klasie:
 
`
class Person
{
    string firstName;
    string lastName;
    int age;
};
`
## Wczytywanie danych
 
Dane uczniów są wczytywane z pliku uczniowie.txt.
 
## Sortowanie
 
Uczniowie są sortowani rosnąco według nazwiska za pomocą algorytmu Bubble Sort.
 
## Wyświetlanie danych
 
Posortowani uczniowie są wyświetlani w konsoli.
 
## Zapisywanie danych
 
Posortowane dane są zapisywane do pliku wynik.txt.
